# KuchuPuchu — Moderation

## User reports
Categories:
- spam
- harassment
- impersonation
- scam
- inappropriate content
- abuse
- suspicious account
- other

## Workflow
submitted → triaged → investigating → actioned/resolved.

## Actions
- no action
- warning
- content removal
- interaction restriction
- temporary suspension
- permanent ban

## Fairness
Moderation actions should have documented reasons and appropriate review/appeal mechanisms.

## Automated controls
Rate limits and abuse detection may automatically restrict suspicious behavior, but high-impact permanent actions should have controlled review.
