# KuchuPuchu — Product Roadmap

## MVP
- Google/email authentication
- Profile
- Free Fire details
- Discovery
- Recommendations
- Duo/Squad requests
- Basic social system
- Blocking/reporting
- Coins
- Referral
- Store
- Inventory
- SPV coin purchase
- Notifications
- Basic admin

## V1
- Messaging
- Reputation
- Verification
- Gifts
- Profile boosts
- Better recommendation engine
- Advanced moderation
- Analytics

## V2
- Events
- Seasonal limited items
- Team/squad communities
- Match history integrations where legitimately available
- Advanced recommendation experimentation
- Creator/community features

## Future constraints
Do not add features merely because they look impressive. Every feature must have a clear user value, security model, data model, and maintenance cost.
