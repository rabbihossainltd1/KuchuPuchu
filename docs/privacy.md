# KuchuPuchu — Privacy Specification

## Principles
- Data minimization.
- Purpose limitation.
- User control.
- Secure storage.
- Transparent privacy settings.

## Location
Use approximate location for discovery. Exact address/location is never public.

Users can choose visibility such as:
- country
- district
- approximate area
- hidden

## Account deletion
Deletion workflow must cover:
- profile
- discovery data
- social relationships where appropriate
- messages according to retention rules
- personal identifiers
- authentication provider linkage

Financial/audit records may require retention according to applicable obligations, while minimizing personal data.

## Data export
Where supported, users can request a structured export of their account data.
