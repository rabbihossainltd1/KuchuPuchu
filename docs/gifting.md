# KuchuPuchu — Gifting

## Rules
- Only giftable inventory can be gifted.
- Sender must own the item.
- Sender and receiver must be eligible.
- Block relationships prevent gifting.
- Transfer is atomic.
- Duplicate transfer is impossible.
- Both parties receive appropriate notifications.
- Gift history is auditable.

## Gift message
Optional short message with abuse filtering and rate limits.

## Anti-abuse
Rate-limit gifting and monitor unusual high-volume transfer patterns.
