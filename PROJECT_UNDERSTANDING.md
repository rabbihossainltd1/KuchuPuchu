## 1. Overview

**KuchuPuchu** is a WhatsApp-style messenger for Free Fire players in Bangladesh:
1:1 and group chat, photos/video/voice/file sharing, 24h statuses, WebRTC 1:1 + group
audio/video calls with screen share, an in-app Gemini AI chat/photo bot, verified/moderator
official accounts, and FCM push. There is deliberately **no** wallet, store, gifting,
matchmaking or payments (those belonged to the abandoned v2 social-network pivot and were
removed). The product is a **Cloudflare Worker (TypeScript) JSON API + D1 + R2 + Durable
Objects** backend and a single **native Android app (Kotlin + Jetpack Compose)**. No web
client and no Node/Express server exist in this tree. It is a live, shipping product: the
worker is deployed at `kuchupuchu-api.kuchupuchu.workers.dev` and Android builds are
distributed as GitHub releases (latest tag `v132`, versionName `3.9.56`, versionCode `132`,
published 2026-09-10) and installed through an in-app updater. Maturity is high: 1,447 worker
test assertions, a custom Android manifest/dependency gate, self-healing DB schema, and
extensive provenance comments ("Owner round N", "§N") on almost every non-obvious decision.

## 4. Entry Points & Flow

- **HTTP**: `export default { fetch, scheduled }` (index.ts:4141). `fetch` answers OPTIONS, then
  `handle()` (index.ts:4286): `await ensureSchema(db)` (memoised per isolate; fingerprint-gated in
  `schema_meta`) → parse path/method/JSON → a long chain of exact `path ===` / `path.match()`
  routes → `json()`/`fail()`. Errors: `ApiError` returns its code; anything else is logged to
  `error_log`, the raw stack is **never** sent to the client, and D1 row-read-quota errors map to
  503 + `Retry-After: 45` (`code: BUSY`).
- **Typical send**: app `POST /api/conversations/:id/messages` with bearer token →
  `requireUser()` (one JOIN on hashed session, throttled presence) → member/block/privacy/rate-limit
  checks → row inserted (`client_id` de-dupe index) → D1 fan-out helpers broadcast a WS event via
  the `ChatRoom` DO (`/ws/chat/:conv`, `/ws/user/:id`) and, for sockets that are not live, an FCM
  push through `pushToUser()` (which mints/caches a Google OAuth token from the PEM in
  `FCM_CREDENTIALS`). Media is first `POST /api/files` (25 MiB cap measured from actual bytes) to
  R2 with a row in `files`; `GET /api/files/:key` authorises owner **or** conversation member **or**
  a membership-referencing message, then streams with `nosniff` + `Content-Disposition: attachment`.
- **Realtime**: DOs only hold sockets and re-broadcast what REST wrote; clients treat frames as a
  trigger to re-sync, so a dropped socket self-heals on the next REST poll. Sockets are receive-only
  from clients (cannot spoof events); the worker injects the verified user via an internal header.
- **Calls**: signalling over `/api/calls*` + `CallSignal` DO; callee discovery via poll of
  `/api/calls/active`; group calls are a mesh with per-pair SDP/ICE (`call_peers`/`call_ice`). The
  per-minute cron + on-read reaper flip abandoned RINGING calls to MISSED and fire the push.
- **Cron `scheduled()`** (index.ts:4189): stale-call reaper (every tick, index-served) →
  due scheduled-message dispatch → hourly (gate `shouldRollupMetrics`) `ensureSchema` + metrics
  rollup + self-origin latency probe → once-daily marker-gated prune of `error_log` (7 d) and
  `devices` (60 d). Each job is in its own try so one failure cannot stop the others.
- **App startup**: `MainActivity`/`KpApp` load session from prefs, fetch `/api/config/firebase`
  (FCM init + Google web client id at runtime), register FCM, then chat list; `KpUpdate.check()`
  conditionally polls GitHub `releases/latest` (ETag/304 aware).

## 7. Data Model (D1 — `kuchupuchu-v3-apac`)

Schema is created/healed by `ensureSchema()` (index.ts:2057) from `CREATE TABLE IF NOT EXISTS` + a
fingerprint in `schema_meta`; additive `ALTER`/`CREATE INDEX` migrations run **outside** the D1
batch and are individually idempotent so a quota error can't roll the base tables back.

- **users** (id PK; legacy `email UNIQUE NOT NULL`, `password_hash NOT NULL` still present —
  phone signups write synthetic email + `''` hash; username UNIQUE; profile; `phone_e164` UNIQUE
  partial, `google_subject` UNIQUE partial; `auth_status` ACTIVE/PENDING; badges `verified` /
  `moderator` / `badge`; privacy columns `priv_phone/avatar/messages/last_seen/groups/status`,
  `read_receipts`, `private_profile`; `avatar_version`).
- **sessions** (token_hash PK — only SHA-256 of the bearer token; user_id; 90-day expiry; device_id).
- **auth_devices** (device registry, UNIQUE(user,device), status PENDING/ACTIVE/REVOKED, ip/city/country);
  **login_requests** (old-device approval, 5 min); **recovery_requests** (Google recovery, 5 min);
  **auth_audit** (event log).
- **devices** (FCM push token PK, user_id, device_id/platform/app_version/last_seen_at).
- **conversations** (SOLO/GROUP; title/owner; avatar_url+avatar_version; `hidden_json`;
  disappear_seconds/since; theme; request_from for stranger message requests; private_group) and
  **members** (PK(conv,user), role, last_read_at, muted, unread, hidden+hidden_key).
- **messages** (id, conv, sender, kind TEXT/IMAGE/VIDEO/AUDIO/FILE/CALL/SYSTEM, body, media key,
  meta_json, reply_to, client_id, delivered_at, created_at) — indexes on (conv,created_at),
  media, dedupe (conv,sender,client_id), partial undelivered.
- **files** (R2 key PK, owner_id, conv_id) is the authorisation table for media.
- **statuses** + **status_views** (reaction stored on the view row); **blocks**;
  **typing** (PK(conv,user), age-expired on read).
- **calls** (1:1 rows; `callee_id=''` marks a group call; offer/answer/reoffer; media_json live
  flags), **call_members** (RINGING/JOINED/LEFT/DECLINED/MISSED), **call_peers** (mesh SDP per pair),
  **call_ice** (target_id for group fan-out).
- **ai_sessions** / **ai_session_msgs** (Gemini conversation state, msg cap),
  **scheduled_messages** ("send later", PENDING/SENDING, cron-driven).
- **metrics_daily** + **metrics_wm** (WITHOUT ROWID daily rollups + high-water marks),
  **error_log** (server stacks; pruned at 7 days).

## 9. Conventions (MUST FOLLOW)

- **Worker** is one file by deliberate history: keep helpers small/pure and ordered logically;
  use `json()` / `fail(status,msg,code)` and the `all/one/run` query helpers; bind every value
  (never string-concatenate SQL); wrap costly fan-out in `ctx.waitUntil`; every hot route is
  statement-budget conscious (tests count round trips — keep list routes' statement count constant;
  test 04 pins it). Add an index for every cleanup `DELETE` (D1 bills rows *scanned*).
- Explain **why**, cite provenance ("Owner round N", "§N", or the bug/date) on non-obvious code —
  this repo's comments are its changelog; match that density instead of restating code.
- Never echo internal errors/SQL to clients; add rate-limit buckets to sensitive routes in the
  existing `rateLimit(key, capacity, perMinute)` style; never trust client lengths — validate
  server-side (message 4,000 chars; bio 160; file 25 MiB; AI photo 7 MB / voice 6 MB; link preview
  1 MB HTML / 2 MB image).
- **Android**: single package `app.kuchupuchu.android`, one file per screen/feature, Compose +
  Material3, framework-integration classes prefixed `Kp`; network goes through the `Api` object
  (which strips the bearer for non-own hosts such as GitHub); payloads are `org.json.JSONObject`;
  pinned versions only (no `+`/floating deps — the validator fails them); ask permissions in
  context; pure-JVM unit tests only (no Robolectric/android stubs); keep `applicationId`
  `app.kuchupuchu.android` unchanged; bump `versionCode` for every released APK.
- Formatting is enforced: Prettier for TS/JSON/MD/YAML; ktlint import rules via `ktlint-check.sh`.
