## 1. Overview
KuchuPuchu is a messenger for Free Fire players: 1:1 + group chat, media/files, 24h statuses, WebRTC audio/video calls with screen share, blocks, FCM push. No web client, no wallet/store/payments (abandoned v2 spec). Mature, owner-tested on real phones in BD, rapid round-based iteration (currently Round 62).

## 4. Entry Points & Flow
- Worker: `export default { fetch: handle(), scheduled }` (~L4950). Typical send: `POST /api/conversations/:id/messages` → `requireUser` (1 D1 stmt) → `requireMember` → dedupe probe → `INSERT..SELECT..WHERE NOT EXISTS` → batch preview/unread → `waitUntil` broadcast + FCM poke.
- App: `MainActivity` → route store; chat polls `GET messages` ~1s (`ChatScreen.kt:1108`); sends via `Api.http` (OkHttp 10s/45s) with `Outbox` queue-first + `paintSent` fast paint.
- Cron: every minute (`wrangler.toml`) reaps stale RINGING calls, sweeps sessions/statuses/stale MPU uploads, runs scheduled-message replay (in-process `handle()` to `scheduled.internal`, same-isolate nonce) and hourly latency probe.

## 7. Data Model

## 8. API Surface
Auth: `verify-phone`, `google/bind`, `login/{poll,cancel,approve,decline}`, `recovery/{lookup,start,complete}`, `refresh`, `logout`, `devices`, `phone/change`. Chat: conversations CRUD, messages GET (cursor) / POST / DELETE (sender-only, permanent), `messages/:id/{media,view}`. Files: POST, MPU start/part/complete/abort. Statuses, calls (`/calls`, `/calls/active`, ICE), blocks/reports, debug (`push`, `clientlog` — key-gated; NOTE: `GET /api/debug/errors` does NOT exist despite old docs). Auth: `Authorization: Bearer <90d token>` (sha256-stored); CORS `*`.
